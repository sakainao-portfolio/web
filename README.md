# 💻 SAKAI NAO ポーフォリオサイト

架空サイトの制作実績やこれまでの経験をご紹介するためのポーフォリオサイトです。

## 🔗 サイトURL
- 公開URL： https://sakainao-portfolio.github.io/web/

## 🛠️ 使用技術
- HTML5 / CSS3 / JavaScript
- SVG Filters (`feTurbulence` / 独自フィルター表現)

## 💡 工夫したポイント・設計
- **トンマナと配色:** トレンドを意識したアナログ感を表現するため、生成り（`#F7F5F0`）とスレートブルー（`#77A9C2`）のグラデーションを背景にし、アクセントカラーとしてくすみテラコッタ（`#C29077`）を採用しました。
- **コード設計:** `outer` → `article` → `section` の階層ルールを意識し、保守性の高いHTML/CSS構造を心がけました。
- **インタラクション:** JavaScriptやCSSアニメーションを用いて、心地よい動きを実装しています。
- **ビジュアル・質感のこだわり:** SVGフィルター（`feTurbulence` 等）を駆使して、デジタルでありながらどこか温かみのあるアナログ感や有機的なエッジを表現しました。
